# Foundations of SQL

# Project Overview

This project introduces the foundational concepts of SQL (Structured Query Language) used to retrieve, filter, organise, summarise and explore data stored in relational databases.

The focus of this project is on:

SELECT

DISTINCT

FROM

WHERE

GROUP BY

LIMIT

These commands provide an important foundation for data analysis because they allow an analyst to retrieve specific information, remove duplicate results, filter records and summarise data.
